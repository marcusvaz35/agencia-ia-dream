# Instagram limita 45 posts programados

- Exemplo real, conta @cliente: ao programar o 46º post apareceu "Não foi possível programar o post"; a resposta do servidor dizia `Exceeded global scheduled content limit: 45 >= 45`.
- Cada post publicado libera uma vaga. Com 3–4 posts/dia, 45 vagas cobrem ~12–15 dias.
- Como aplicar: antes de programar lote grande, contar quantos já estão programados (scheduled_content); programar no máximo até 45 e deixar o resto para quando liberar (ex.: rodada noturna). Nunca apagar post programado para abrir vaga sem OK do CEO.

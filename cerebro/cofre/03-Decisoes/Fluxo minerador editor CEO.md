# Fluxo minerador editor CEO

- Desde 11/11/2026: minerador → **social-media** (agenda + briefing com prazo em `demandas/`) → editor → CEO aprova → social-media agenda (com OK) e cuida dos comentários (respostas só com OK do CEO por lote).
